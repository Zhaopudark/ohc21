0.9.0
=====
Forked from org.caffinitas.ohc 0.7.4, with ongoing development targeting the current mainstream and stable Java platform (Java 21).

Notice:
Current version will start from 0.9.x
The current version is a simple replica, without much customized modification.
In the future, more modern changes will be made on this forked branch for on Java 21 edition,
gradually consolidating the API levels of the off-heap cache implementation and removing `unsafe`.
