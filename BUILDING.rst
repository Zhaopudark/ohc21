Building OHC from source
========================

This fork (ohc21) targets Java 21.

OHC can be built from source using Java 21 or newer. The generated bytecode targets Java 21,
and OHC runs against Java 21 and newer (support for Java 20 and earlier has been dropped in this fork).

::

    mvn clean install

The current implementation still depends on ``sun.misc.Unsafe`` and the non-exported
``sun.nio.ch`` package. Building and running therefore require exporting ``java.base/sun.nio.ch``:

- at compile time this is configured in ``pom.xml`` (``maven-compiler-plugin`` ``--add-exports`` compiler arg)
- at test/runtime it is configured via the ``surefire.jvmargs`` property
  (``--add-exports java.base/sun.nio.ch=ALL-UNNAMED``)

These ``--add-exports`` are needed because the off-heap implementation still uses
``sun.nio.ch.DirectBuffer``. Removing them requires migrating to ``java.lang.foreign.MemorySegment``
(FFM), which is only a *preview* feature in JDK 21 (JEP 442; finalized in JDK 22 / JEP 454). That
migration is prototyped on branch ``feature/b1-ffm`` and deferred to JDK 22 (see
``docs/jdk21-migration/jdk21-migration.md``); it is **not** part of this build.

The ``ohc-benchmark`` and ``ohc-jmh`` modules are enabled in the reactor (restored in task C1).
To build without running the JMH microbenchmarks during ``install``::

    mvn clean install -DskipJmh

Unit tests run against three surefire executions (jna allocator + debug, unsafe allocator + debug,
and a production-like jna run without debug).

Releasing to Maven Central
--------------------------

Releasing is a local, manual Maven flow (no CI) that uploads to the Sonatype **Central Portal**
via ``central-publishing-maven-plugin`` (``deploy`` profile). The previously bundled Atlassian
``jgitflow`` plugin and the legacy OSSRH ``<distributionManagement>`` block have been **removed**
in favor of a direct ``mvn deploy -Pdeploy``. Publishing **must** use the non-preview build on
``master`` (never the ``feature/b1-ffm`` preview line). See
``docs/jdk21-migration/release-runbook.md`` for prerequisites (GPG key, ``~/.m2/settings.xml``
server id ``central`` token) and step-by-step commands.
